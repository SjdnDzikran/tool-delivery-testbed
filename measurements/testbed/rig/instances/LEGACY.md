# Legacy instance templates

These six `{eager-mcp,deferred-mcp,cli-skills}--{gpt6luna,glm53flash}` directories are historical configuration examples, not deployment inputs:

- `mcp.json` contains `PIN_VERSION` placeholders.
- The manifest-driven runner generates a fresh agent directory from a manifest.
- These drafts use an older skill naming convention.

Do not execute trials from these directories. Use and review a manifest under `../examples/` instead.
